# Planes — Features

Planes de trabajo para features y cambios mayores del proyecto. Un plan por archivo
(markdown con lista de tareas en checkboxes). Al crear un plan, regístralo aquí.

Cada plan: objetivo, estado actual, estrategia, lista de tareas (`- [ ]`) y validación.
Marca las tareas a medida que se completan.
